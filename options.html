Settings

Tab history

Search always includes all open tabs, regardless of the trail size. Reducing the limit trims the trail while keeping its current position.

Keyboard shortcuts

Chromium requires shortcut changes to be made on its extension-shortcuts page. The mappings below distinguish registered commands with no keys assigned from commands missing in this browser profile.

Extension reload required

A command is not registered in the running extension. Reload Tab Trail to load the updated manifest, then reopen Settings and the browser's shortcut page. Saved names, trail settings, and existing shortcuts are retained.

The search shortcut is not assigned. On the shortcut page, set Activate the extension to Ctrl + Shift + Q.

Search is listed as Activate the extension in the browser's shortcut editor. Set Copy selected tab links to Alt + Shift + C. Chromium permits only four default shortcuts, so this additional command must be assigned on that page.

Configure the keys

Copy the address for your browser, paste it into the address bar, and edit Tab Trail's commands. Set Previous active tab to Alt + Shift + Left and Next active tab to Alt + Shift + Right if either was cleared.
